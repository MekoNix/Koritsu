### Ошибки (неверный вывод)
- [x] C#: члены интерфейса помечаются `private` (в C# они неявно public).
- [x] C#: любое свойство печатается как `{ get; set; }` — хардкод; `{ get; }`, `{ get; private set; }`, `=>` теряются.
- [x] C++: `int a_, b_;` — берётся только первый declarator (`child_by_field_name("declarator")`), `b_` молча теряется.
- [x] C++: указатель на функцию `void (*cb)(int);` попадает в методы под именем `(*cb)`.
- [x] C++: массив `int arr[10]` → тип `int`, размер теряется.
- [x] builder `_bare_type`: для вложенных generics берётся самый внутренний (`shared_ptr<Base<T>>` → `T`, `List<Dictionary<K,V>>` → мусор) — связи уходят не к тому классу.
- [x] `_method_types`: `params int[] rest` → `paramsint`, `ct = default` — значения по умолчанию не отбрасываются.
- [x] objektis: динамические бэкенды (exec в subprocess, `dotnet run`) удалены — пользовательский код не выполняется (решение 2026-08-27, безопасность). Осталась IR + builder; фасад возвращает пустой граф с заметкой.
- [x] objektis: статические бэкенды Python (`py_static`), C# (`cs_static`, `Main()`), C++ (`cpp_static`, `main()`).

### Что теряется при извлечении
- [x] C#: `enum`, `record`, (`delegate` — не извлекается, редко нужен на диаграмме), вложенные типы (`class Nested` внутри класса) — не извлекаются вовсе (и как классы, и как цели связей: поле `Status St` не даёт ребра).
- [x] C#: событий, индексаторов, операторов, деструктора нет в методах/полях; `static`/`abstract`/`virtual`/`override`/`readonly`/`const` не отражаются (UML: static — подчёркивание, abstract — курсив).
- [x] C#: `internal protected` / `private protected` → просто `protected`; generic-параметры класса теряются (`Base<T>` → `Base`, `where` тоже).
- [x] C++: `template<class U> void tmpl(U)` внутри класса не распознаётся (`template_declaration` в теле не обрабатывается); `enum class`, `union`, вложенные `class Inner`, `using Ptr = …`, `friend` — пропускаются; `static`/`virtual`/`= 0`/`const`-методы/`override`/`final` не отражаются; деструктор помечен как конструктор; `const std::string&` в возвращаемом типе → `std::string`.
- [x] Связи: нет кратностей (сделано, кроме одного цвета для наследования/реализации — в раскладке) (`List<Shape>` → композиция без `*`, должна быть агрегация с `0..*`), нет ролей/подписей на рёбрах; `shared_ptr/unique_ptr` считаются композицией; наследование и реализация одним цветом.
