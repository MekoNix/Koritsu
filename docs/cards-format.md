# Формат набора карточек «Тренажёра»

Набор — файл JSON (`.json`, UTF-8): объект с названием, рекомендуемыми настройками и массивом
карточек. Его можно написать руками, получить от агента или скачать из тренажёра — «Скачать»
отдаёт файл в этом же формате. Вторым входом принимается таблица CSV/TSV (в конце страницы).
Файлы Markdown `.md` не принимаются: Markdown остаётся только **внутри строк** вопроса, ответа
и разбора.

## Пример

```json
{
  "format": "koritsu.cards",
  "version": 1,
  "title": "Матанализ: определённый интеграл",
  "description": "Вопросы к экзамену, 1 семестр",
  "language": "ru",
  "defaults": {"session_size": 20, "order": "topic_random", "include": "all", "repeat_wrong": true},
  "cards": [
    {
      "id": "c-0001",
      "topic": "Первообразная",
      "q": "Что такое первообразная?",
      "a": "Функция $F$, для которой $F' = f$ на всём промежутке.",
      "note": "Частая ошибка — забыть про константу: первообразных бесконечно много."
    },
    {
      "topic": "Первообразная",
      "q": "Найдите первообразную функции\n\n$$f(x) = 3x^2 + 2x$$",
      "a": "$F(x) = x^3 + x^2 + C$"
    },
    {
      "topic": "Интеграл Римана",
      "q": "Вычислить $\\int_0^1 x^2\\,dx$.",
      "a": "$\\frac13$"
    }
  ]
}
```

Полные примеры: `packages/cards/samples/matan.json` (темы, формулы, разборы, id, настройки) и
`packages/cards/samples/plain.json` (только карточки: без названия, тем и id).

## Поля набора

| Поле | Обязательно | Что |
|---|---|---|
| `format` | нет | `"koritsu.cards"`. Другое значение — проблема файла, набор читается |
| `version` | нет | `1`. Больше `1` — отказ «файл новее тренажёра» |
| `title` | нет | название набора, одна строка до 200 символов; без него — имя файла |
| `description` | нет | описание, до 2000 символов |
| `language` | нет | код языка: `"ru"`, `"en"`; по умолчанию `"ru"` |
| `defaults` | нет | рекомендуемые настройки захода (ниже) |
| `cards` | **да** | непустой массив карточек |

`format` и `version` писать необязательно, но «Скачать» и агент ставят их всегда.

## Поля карточки

| Поле | Обязательно | Что |
|---|---|---|
| `q` | **да** | вопрос: непустая строка, Markdown и формулы |
| `a` | **да** | ответ: непустая строка, Markdown и формулы |
| `topic` | нет | **название** темы строкой. Нет, `null` или `""` — карточка без темы |
| `note` | нет | разбор: показывается под ответом свёрнутым |
| `id` | нет | устойчивый id: латинские буквы, цифры, `.`, `_`, `-`, от 1 до 64 знаков, уникален в наборе |

- **Темы** задаются только полем `topic` у карточек. Одинаковые названия (без учёта регистра и
  лишних пробелов) — одна тема. Порядок тем — по первому появлению в `cards`.
- **Лишние поля** набора и карточки молча пропускаются.
- **Число** в текстовом поле (`"a": 42`) читается строкой `"42"`. Массив, объект, `true`/`false`
  — проблема поля.
- **id и прогресс.** По id новая версия файла сохраняет прогресс даже при изменённой
  формулировке. Карточка без id узнаётся по тексту вопроса без учёта регистра и лишних пробелов:
  поменяли формулировку — это новая карточка, прогресс по старой не переносится. id вида `q-` и
  16 шестнадцатеричных знаков тренажёр выдаёт сам при скачивании — менять их не нужно.

## Обратный слеш и перевод строки

Строка JSON сама использует обратный слеш для escape-последовательностей, поэтому:

| Нужно в карточке | В JSON пишется |
|---|---|
| `\int`, `\frac`, `\alpha` | `"\\int"`, `"\\frac"`, `"\\alpha"` — слеш **удваивается** |
| `\,` (тонкий пробел в формуле) | `"\\,"` |
| `\\` (перенос строки в `aligned`) | `"\\\\"` |
| перевод строки | `"\n"` |
| пустая строка между абзацами | `"\n\n"` |
| кавычка `"` | `"\""` |
| `C:\Users` в коде | `"C:\\Users"` |

Неудвоенный слеш опасен молча: `\t`, `\n`, `\b`, `\f`, `\r` — законные последовательности JSON, и
`"\theta"` превращается в табуляцию и слово `heta`, `"\frac"` — в управляющий символ и `rac`,
`"\nabla"` — в перевод строки и `abla`. Тренажёр узнаёт такие места по имени команды LaTeX и
отклоняет карточку с подсказкой (`latex_escape`). Остальные одиночные слеши (`"\int"`) дают
битый JSON с номером строки и столбца.

Формула на отдельных строках:

```json
{"q": "Правило Лопиталя?", "a": "$$\n\\lim_{x\\to a}\\frac{f(x)}{g(x)} = \\lim_{x\\to a}\\frac{f'(x)}{g'(x)}\n$$"}
```

## Что можно внутри вопроса, ответа и разбора

Абзацы, **жирный**, *курсив*, `код`, блоки кода, списки, таблицы, цитаты, заголовки, черта `---`,
формулы KaTeX `$…$` и `$$…$$`.

Нельзя: сырой HTML (`<div>`, `<br>`, `<iframe>`), картинки `![](…)`, ссылки `[текст](адрес)`,
`<https://…>` и голые адреса `https://…`, команды `\href`, `\url`, `\includegraphics`,
`\htmlClass` и подобные, управляющие символы. Внутри блоков кода и `код` — можно всё: там это
просто текст. Незакрытый блок кода или формула `$$` — проблема карточки.

## Рекомендуемые настройки `defaults`

Все поля необязательны; у каждого человека настройки свои, а эти — стартовые.

| Поле | Значения | По умолчанию |
|---|---|---|
| `session_size` | число карточек за заход; `0` или `"all"` — все | `20` |
| `order` | `"file"` по файлу · `"random"` случайно · `"topic_seq"` по темам подряд · `"topic_random"` по темам, внутри случайно · `"topics_shuffled"` темы вперемешку, внутри подряд | `"topic_random"` |
| `topics` | массив названий тем, `""` — карточки без темы; `null` — все темы | все темы |
| `include` | `"all"` все · `"unknown"` ещё не знаю · `"wrong"` только «Нет» | `"all"` |
| `repeat_wrong` | `true` / `false` | `true` |

Неизвестное значение — проблема файла, берётся значение по умолчанию.

## Потолки

Файл — до 5 МБ, карточек — до 10 000, тем — до 500, вопрос, ответ и разбор — до 20 000 символов
каждый, название набора и темы — до 200 символов.

## Проблемы разбора

Разбор не отказывает молча. У каждой проблемы — код, объяснение по-русски и место:

- **путь JSON** поля: `cards[12].a` — ответ тринадцатой карточки (счёт с нуля), `defaults.order`;
- **номер карточки** `card` (с нуля) — такая карточка отклонена; без номера проблема касается
  файла целиком и карточек не отклоняет;
- **строка и столбец** — у файла, который не читается как JSON, и у строк CSV.

Файл с отклонёнными карточками можно исправить или сохранить только годные — сколько из
скольких, показывается явно. Битый JSON — одна проблема, набора нет:

```
строка 14: файл не читается как JSON — строка 14, столбец 5: ожидалось значение — нет ли лишней
запятой перед `]` или `}`, строки в одинарных кавычках или комментария
```

## Частые ошибки

| Ошибка | Что происходит | Как правильно |
|---|---|---|
| `"\int"` вместо `"\\int"` | Битый JSON: неизвестная escape-последовательность | Удвоить слеш |
| `"\theta"`, `"\frac"`, `"\nabla"` | Карточка отклонена (`latex_escape`) | `"\\theta"`, `"\\frac"`, `"\\nabla"` |
| Перевод строки прямо внутри `"…"` | Битый JSON | `\n` |
| Запятая после последнего элемента: `[{…},]` | Битый JSON | Убрать запятую |
| Одинарные кавычки `'q': 'текст'` | Битый JSON | Только двойные кавычки |
| Комментарии `// …` | Битый JSON | В JSON комментариев нет; лишнее поле вроде `"_comment"` пропускается |
| Массив карточек без обёртки: `[{…}]` | Набор не читается | `{"cards": [{…}]}` |
| Карточка без `a` или с пустым `a` | Карточка отклонена: `у карточки нет ответа` | Написать ответ |
| `"topic": ["Предел"]` | Проблема поля, карточка отклонена | `"topic": "Предел"` |
| id темы вместо названия: `"topic": "predel"` | Получится тема «predel» | Название, как его показать человеку |
| Две карточки с одинаковым вопросом без id | Проблема у второй: карточки не различить | Переформулировать или дать обеим разные `id` |
| Одинаковые `id` | Проблема у второй | id уникальны |
| id по-русски: `"вопрос-1"` | Проблема: id только латиницей | `"q-1"` |
| Картинка или ссылка в ответе | Проблема карточки | Описать словами или формулой |
| Файл `.md` прежнего формата | Отказ: формат Markdown не поддерживается | Перевести набор в JSON |

## CSV и TSV

Колонки `вопрос, ответ[, тема[, разбор]]`, без id. Разделитель — табуляция, `;` или `,`
(определяется по первой строке); заголовок `вопрос,ответ` пропускается. Экспорт Anki
«Notes in Plain Text» и Quizlet подходит как есть. Проблемы указывают номер строки таблицы.

Загруженная таблица сразу становится файлом JSON: в черновике видны все её карточки, в том числе
отклонённые, и «Скачать» у готового набора отдаёт уже `.json`. Правила содержимого — те же.
