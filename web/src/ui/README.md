# `src/ui` — общие компоненты

Radix (без стилей) + Tailwind по переменным темы. Radix берёт на себя то, что
руками пишется неделю и всё равно с дырами: фокус, клавиатуру, роли, порталы.
Здесь — только вид по макетам `~/koritsu2-extras/labs/refsheet`.

Одна дверь: `import { Button, EmptyState, useToast } from '@/ui'`.

## Что есть

| Компонент                                                                     | Коротко                                                                                                          |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `Button`                                                                      | `variant`: primary / secondary / ghost / danger / **agent**; `size`: sm/md/lg; `iconOnly`, `loading`, `asChild`. |
| `Input`, `Textarea`, `PasswordInput`, `Field`                                 | Подпись, подсказка, ошибка; `aria-invalid` и `aria-describedby` расставлены сами.                                |
| `Icon`                                                                        | Инлайн-SVG. Список имён — `IconName`.                                                                            |
| `Dialog`                                                                      | Модалка на Radix: ловушка фокуса, `Esc`, возврат фокуса. Заголовок обязателен.                                   |
| `MenuRoot / MenuTrigger / MenuContent / MenuItem / MenuSeparator / MenuLabel` | Выпадающее меню; `MenuItem` умеет `icon` и `danger`.                                                             |
| `ToastProvider`, `useToast`                                                   | Тосты.                                                                                                           |
| `Skeleton`, `SkeletonLines`, `Spinner`                                        | Загрузка.                                                                                                        |
| `EmptyState`, `ErrorState`, `ForbiddenState`                                  | Обязательные состояния §7.                                                                                       |
| `Avatar`                                                                      | Генеративный identicon из id.                                                                                    |
| `Badge`                                                                       | Счётчик-кружок.                                                                                                  |
| `Card`, `Row`                                                                 | Карточка раздела (заголовок, пояснение, кнопки справа) и строка «подпись — значение».                            |
| `Segmented`                                                                   | Переключатель-сегменты; по разметке — `radiogroup`.                                                              |
| `Select`, `Switch`                                                            | Родной `<select>` в обёртке `Field` и тумблер.                                                                   |
| `Chip`, `Progress`                                                            | Пилюля состояния и полоса заполнения.                                                                            |
| `CopyButton`                                                                  | «Скопировать»; успех показывается на кнопке, а не тостом.                                                        |

Шесть последних приехали сюда на сведении ночи 1 из
`features/settings/parts.tsx`: их завела область настроек (пятеро агентов в
одном дереве не могут одновременно писать в `ui/`), а брала уже и админка.
Своего `Segmented` у схем это не отменяет — там он с подсказкой у сегмента и
сводится ночью 2.

## Правила, которые здесь закон

**Цвет — только из темы.** Никаких `bg-[#1a1a1a]` и `text-gray-500`: классы
Tailwind разворачиваются в переменные (`bg-surface` → `var(--surface)`), и
смена темы перекрашивает всё разом. Прозрачность через `/50` у таких цветов
не работает — значение переменной готовый цвет, а не тройка каналов; берите
готовую переменную (`--accent-bg`, `--ok-bg`) или `color-mix`.

**Цвет агента отличается от акцента.** Всё, что сделала модель, красится
`--agent` (`variant="agent"`, `text-agent`, `bg-agent-bg`) — требование
спецификации: человек должен за полсекунды отличать своё от сгенерированного.

**Иконка декоративна.** У `Icon` стоит `aria-hidden`; подпись даёт кнопка
рядом или `aria-label` на кнопке. Кнопка с одной иконкой без `aria-label` —
ошибка.

**Видимый фокус не убирается нигде.** Он объявлен глобально в
`styles/index.css`; `outline: none` без замены — это слепая клавиатура.

## Как добавить

**Иконку** — строка в `PATHS` (`Icon.tsx`), `viewBox="0 0 24 24"`, обводка,
без заливки. Больше ничего: размер, цвет и доступность общие.

**Свой компонент** — новым файлом в `src/ui/` плюс строка экспорта в
`index.ts`. Существующие файлы не переписываются: на них уже завязаны четыре
области.

**Не в `ui/`, а в свою область** идёт всё, что знает про предметку: карточка
проекта, панель тегов, редактор схемы. `ui/` — это кнопки и состояния, а не
экраны.

## Тосты

```ts
const toast = useToast()
toast.success('Отчёт готов', 'Лабораторная 4 — PDF собран')
toast.error(errorText(e))
```

Тостить можно **только завершение фоновой задачи и ошибку** (решение
владельца). Всё остальное — в колокольчик, он уже читает `/api/notifications`.
`toast.info('сохранено')` — повод убрать вызов, а не добавить вид.

## Состояния экрана

Спецификация §7 требует их от каждого экрана. Обычный набор:

```tsx
if (query.isLoading) return <SkeletonLines count={5} />
if (query.isError) return <ErrorState error={query.error} onRetry={query.refetch} />
if (!items.length) return <EmptyState title={t('…')} text={t('…')} action={<Button …/>} />
```

`ErrorState` сам берёт русский текст по коду службы (`errorText`) — второй раз
переводить не надо.
